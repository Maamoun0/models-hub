# 🧠 AI Models Hub — The Ultimate Model Comparison Engine

**AI Models Hub** is a premium, high-performance web platform designed to compare, analyze, and discover the best Artificial Intelligence models for any task. From technical benchmarks to pricing and capabilities, it provides a comprehensive view of the AI landscape.

## 🌟 Features

- **Side-by-Side Comparison**: Compare up to three models simultaneously across a wide range of criteria.
- **Detailed Model Specs**: Deep dive into individual model specifications, including context window size, training data cutoff, and primary use cases.
- **Performance Matrix**: Visual representation of reasoning, coding, creativity, and speed scores.
- **Search & Filter**: Easily find models based on provider (OpenAI, Anthropic, Google), type (Multimodal, LLM), or capability.
- **Export Reports**: Generate PDF reports of model comparisons for stakeholders.

## 🛠️ Technology Stack

- **Frontend**: Next.js 15+ (App Router), TypeScript.
- **Database**: Prisma (PostgreSQL ready).
- **Styling**: Tailwind CSS 4.0, Glassmorphism UI.
- **Animations**: Framer Motion.
- **Icons**: Lucide React.

## 📖 How to Run

1. Clone the repository.
2. Install dependencies: `npm install`.
3. Set up your `.env` file (see `.env.example`).
4. Run Prisma migrations (if applicable): `npx prisma generate`.
5. Start the development server: `npm run dev`.
6. Open `http://localhost:3000` in your browser.
